# Game Domain

`@guandan/game-domain` will contain deterministic, environment-independent Guandan rules and domain models. It is currently an intentionally empty package scaffold; card identities, combinations, validation, tribute, scoring, and progression are not implemented.

The package must remain independent of Node.js, browsers, React, Expo, server frameworks, and persistence libraries.

Run from the repository root:

```sh
npm run shared:typecheck
npm run shared:build
```
